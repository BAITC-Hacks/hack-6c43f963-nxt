# Повод — подбор event-подрядчиков

Laravel 13 + Livewire 4 + Flux UI. Один публичный экран: параметры мероприятия → до трёх подходящих профилей → проверяемые объяснения. Данные — 66 исходных профилей в `storage/app/private/contractors.csv`.

## Запуск

Требования: PHP 8.4+, Composer, Node.js с npm.

```sh
composer install
```

Скопируйте `.env.example` в `.env`, если файла ещё нет. Для существующего `.env` задайте:

```dotenv
SESSION_DRIVER=file
CACHE_STORE=file
QUEUE_CONNECTION=sync
```

```sh
php artisan key:generate
npm install
npm run build
php artisan config:clear
php artisan serve
```

Для этого сценария база данных, миграции и очередь не нужны. `key:generate` нужен только при первом запуске без ключа. Не используйте `composer run setup` для запуска без БД: унаследованный скрипт стартового шаблона запускает миграции. Авторизация и dashboard из стартового шаблона не входят в сценарий MVP.

## Правила подбора

- `App\Services\ContractorCatalog::all(): array` читает CSV через `storage_path()`, обрабатывает BOM и возвращает нормализованные профили.
- `ContractorCatalog::options(): array` возвращает `cities`, `categories`, `event_formats`, `languages` — уникальные отсортированные списки.
- `ContractorMatcher::match(array $criteria): array` получает `city`, `date`, `category`, `event_format`, целый `budget`, nullable `hours` и `language`. Ввод проверяется Livewire-компонентом до вызова сервиса.
- PHP строго проверяет город, категорию, отсутствие даты в `busy_dates`, цену не выше бюджета, формат, необязательные язык и часы. Пустой `max_hours` означает неизвестный лимит: такой профиль не исключается, но карточка предлагает уточнить длительность.
- Даты ограничены интервалом 23.09.2026–31.12.2026. Бюджет: целое число 1–1 000 000 000 ₸; длительность: целое число 1–24 часа.
- Статусы результата: `matched`, `no_category`, `no_matches`. Причины исключения считаются независимо и могут пересекаться.
- Без AI кандидаты сортируются по цене, затем по строковому ID. Выбираются первые три. Цена всегда показывается как «от».
- `synthetic` явно маркируется. Восстановленные город и цена тоже отмечены. Каталог не подтверждает бронирование или итоговую стоимость.

## AI и резервный алгоритм

Установлен официальный `laravel/ai`. По умолчанию AI выключен, приложение полностью работает без внешнего API.

Для включения настройте `.env`:

```dotenv
CONTRACTOR_AI_ENABLED=true
CONTRACTOR_AI_PROVIDER=openai
CONTRACTOR_AI_MODEL=
OPENAI_API_KEY=ваш_ключ
CONTRACTOR_CACHE_STORE=file
```

Пустой `CONTRACTOR_AI_MODEL` использует модель по умолчанию установленного SDK. Другие провайдеры SDK можно выбрать через `CONTRACTOR_AI_PROVIDER`, указав их соответствующий ключ окружения. Затем выполните `php artisan config:clear`. Ключи не коммитятся.

`AiContractorRanker` передаёт модели только уже прошедшие фильтры профили и параметры события. Модель выбирает порядок и пару `id + explanation` для каждого результата. Для достоверности `explanation` ограничен дословной цитатой из описания длиной до 360 символов. PHP проверяет число результатов, уникальность и допустимость ID, непустую цитату и её присутствие в описании именно этого профиля. Проверенные факты о цене, формате, языке и часах добавляет PHP. Произвольные утверждения модели не отображаются.

Таймаут запроса — 8 секунд. Успешный результат сохраняется в файловом кэше без срока истечения; ключ включает параметры события, содержимое подходящих профилей, провайдера, модель и версию запроса. Блокировка предотвращает разные ответы на одновременные одинаковые запросы. Повторная выдача стабильна, пока кэш сохранён и конфигурация/каталог не изменены. После очистки кэша модель может выбрать другой порядок.

Отсутствие ключа, ошибка, таймаут, неверный ID, дубликат или неподтверждённая цитата приводят к резервному алгоритму. Ошибки не кэшируются: после восстановления AI следующий запрос может перейти с резервного порядка на AI-порядок. На странице явно указан способ подбора. Реальный внешний AI-вызов требует вашего ключа; автоматические тесты используют подмену SDK без сетевых запросов.

## Витрина и ИИ-чат

На главной — витрина с кадрами форматов (`public/images/showcase/`) и боковой NLP-чат на модели Alem `qwen3-8` (`OPENAI_COMPATIBLE_URL=https://llm.alem.ai/v1`). Чат говорит свободно, уточняет город, формат, категорию, дату и бюджет. Обязательные условия по-прежнему проверяет PHP (`ContractorMatcher`). Если модель недоступна, включается пошаговый запасной режим с чипами. В конце чат заполняет форму и показывает до трёх карточек.

```sh
php vendor/bin/phpstan analyse --memory-limit=512M
npm run build
```

Полный набор тестов стартового приложения: `php artisan test --compact`.

Покрыты реальные 66 записей, BOM, типы и текст, все фильтры и их границы, пересечение причин, два пустых состояния, смена даты, повторный запрос, маркировка synthetic, валидация формы, отсутствие запросов к БД, проверка и кэширование AI-ответов, резервный режим при ошибках.
