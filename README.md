# seelect — умный подбор event-подрядчиков

**Хакатон-задача:** [#79-lite — умный подбор подрядчиков](https://docs.google.com/document/d/1rhR2HFY164BrnkIP39N3usY9fNY4JeAgkPxEzbqL00w/edit?tab=t.9tqw3yk75922#heading=h.t2seklf6n24)  
**Стек:** Laravel 13 · Livewire 4 · PHP 8.4 · Alem `qwen3-8` (опционально)  
**Данные:** 66 анонимизированных профилей (`storage/app/private/contractors.csv`)

> Заказчик уже выбрал формат и город. **seelect** не удлиняет каталог — помогает **выбрать из списка** и объясняет, почему именно эти до 3 карточек.

## 1. Ценность решения (25)

### Проблема

Организатор свадьбы, той, корпоратива или конференции в Казахстане уже видит каталог подрядчиков. Боль — не «найти ещё 50 ссылок», а:

- кто **свободен в нужную дату** (календарь густой, особенно в декабре);
- кто **влезает в бюджет**;
- кто **берёт этот формат / язык / длительность**;
- и **почему** система предлагает A, а не B.

### Что даём аудитории

| Для кого | Польза |
| --- | --- |
| Заказчик события | До 3 понятных вариантов вместо ручного перебора 66 карточек |
| Площадка-агрегатор | Рекомендация с объяснением → выше доверие и конверсия в контакт |
| Жюри / продукт | Ценность в **объяснении**, не в «умной» сортировке ради сортировки |

**Очевидность пользы в демо:** карточки нельзя перепутать, если стереть имена — у каждой своя причина (бюджет / формат / цитата из описания / занятость на другую дату).

## 2. Результат и качество решения (20)

### Соответствие заданию (#79-lite)

| Требование | Реализация |
| --- | --- |
| Вход: город, дата, формат, категория, бюджет; опц. часы и язык | Форма + ИИ-чат |
| Выход: ≤3 карточки с именем, категорией, городом, ценой «от» и 1–2 предложениями объяснения | Livewire-результаты |
| Занятые на дату не попадают в выдачу | `busy_dates` в `ContractorMatcher` |
| Меньше трёх — показать сколько есть и почему | Сообщение + блок причин исключения |
| Детерминизм: тот же запрос → тот же порядок | Без AI: цена → ID; с AI: кэш ответа |
| Три исхода явно различимы | `matched` / `no_category` / `no_matches` |
| Без общих фраз («отличный выбор…») | Объяснения из фактов каталога + цитаты описания |
| Ответ за разумное время | PHP-фильтр мгновенно; AI-ранжирование с таймаутом и fallback |

**Вне скоупа задания (бронирование):** в UI есть профиль и **заявка на запись** как демо-слой контакта; ядро MVP по ТЗ — **рекомендация с объяснением**.

### Definition of Done — чеклист живой проверки

- [ ] Ответ на запрос приходит быстро (ориентир ≤10 с; без AI — сразу).
- [ ] Объяснения не взаимозаменяемы между карточками одного запроса.
- [ ] Повтор тех же параметров → тот же порядок.
- [ ] Та же форма на **две разные даты** → разная выдача (занятость).
- [ ] Показаны ≥3 сценария: плотная категория / редкая / пустой результат.
- [ ] Пустой результат объяснён словами, не белым экраном.
- [ ] Команда объясняет пайплайн жюри (см. раздел ниже).

### Воспроизводимое демо (AI выключен)

`CONTRACTOR_AI_ENABLED=false`, язык и часы пустые:

| # | Сценарий | Параметры | Ожидание |
| --- | --- | --- | --- |
| 1 | Плотная категория | Алматы · Ведущий · свадьба · **23.09.2026** · 1 500 000 ₸ | 3 карточки: Мицури Канроджи (`HK-44923`), Эмилия (`HK-42352`), Сон Гоку (`HK-27222`) |
| 1b | Та же форма, другая дата | … · **24.09.2026** · … | Кики (`HK-35215`) — один вариант; видно влияние календаря |
| 2 | Редкая категория | Алматы · Флорист · свадьба · 23.09.2026 · 500 000 ₸ | Тони Тони Чоппер (`HK-39372`), Тихиро Огино (`HK-90001`, **синтетический**) |
| 3a | Нет категории в городе | Зарубежье · Флорист · … | Исход «Пока нет в каталоге» |
| 3b | Кандидаты есть, условия не проходят | Алматы · Флорист · … · бюджет **1** ₸ | Исход «Нужны другие условия» + «Цена выше бюджета» |

### Дополнительно в продукте (для демо UX)

- Фото профилей, панель «Подробнее», кнопка «Записаться».
- Витрина форматов → быстрый старт чата.
- Интерфейс **kk / ru**.

## 3. Инновационность (15)

Не «ещё один фильтр каталога», а связка:

1. **Честные правила на PHP** — занятость, бюджет, формат, язык, часы. LLM не может «дорисовать» свободную дату.
2. **LLM только там, где нужна речь** — ранжирование и объяснения среди уже отфильтрованных; цитаты проверяются по тексту профиля.
3. **NLP-чат (Alem qwen3-8)** — заказчик пишет как другу; сервис собирает критерии и запускает тот же matcher.
4. **Fallback без ключа** — продукт работает офлайн по правилам; AI усиливает, но не ломает DoD.
5. **Прозрачные флаги датасета** — `synthetic`, imputed city/price видны в UI (честность к данным хакатона).

## 5. Презентация, демо и ответы жюри (20)

### Скрипт демо (~3 минуты)

1. **Проблема (20 с):** «Каталог есть, выбора с доверием нет — занятость и бюджет проверяют вручную».
2. **Форма (40 с):** плотная категория 23.09 → 3 карточки, прочитать **разные** объяснения вслух.
3. **Дата (30 с):** сменить на 24.09 → другая выдача (календарь).
4. **Редкая / пустая (40 с):** флорист → 2 карточки + synthetic; бюджет 1 ₸ → понятный пустой исход.
5. **Чат (30 с):** одной фразой на kk/ru собрать критерии (если есть ключ Alem).
6. **Пайплайн (20 с):** «сначала правила, потом речь модели».

### Пайплайн «что внутри»

```text
Параметры (форма или NLP-чат)
        │
        ▼
ContractorCatalog  ←  CSV (66 профилей + photo)
        │
        ▼
ContractorMatcher  ←  жёсткие фильтры (city, category, busy_dates, budget, format, language, hours)
        │
        ├── 0 в категории города     → status: no_category
        ├── есть кандидаты, 0 ok     → status: no_matches + reasons[]
        └── eligible ≥ 1
                │
                ├── AI off / ошибка / таймаут → sort(price, id) → top 3 + PHP explain()
                └── AI on → AiContractorRanker → проверка id/цитат → top 3 + факты от PHP
                │
                ▼
        Карточки (фото, объяснение) → Подробнее / заявка (демо)
```

### Типичные вопросы жюри

| Вопрос | Короткий ответ |
| --- | --- |
| Почему не fine-tune на 66 записях? | Пересказ датасета; по ТЗ лучше API LLM + правила. |
| Может ли модель предложить занятого? | Нет: занятость режет PHP до ранжирования. |
| Откуда детерминизм? | Без AI — стабильный sort; с AI — кэш по ключу критериев+кандидатов. |
| Чем лучше Excel-фильтра? | Объяснения, три явных исхода, чат, проверяемые цитаты, UX shortlist. |
| Где ключи API? | Только в `.env`, не в репозитории. |

## Быстрый старт (воспроизводимость)

Требования: PHP 8.4+, Composer, Node.js + npm. **БД и миграции для MVP не нужны.**

```sh
composer install
cp .env.example .env   # если .env ещё нет
php artisan key:generate
npm install
npm run build
php artisan config:clear
php artisan serve
```

Минимум в `.env`:

```dotenv
APP_NAME=seelect
SESSION_DRIVER=file
CACHE_STORE=file
QUEUE_CONNECTION=sync
CONTRACTOR_AI_ENABLED=false
```

Опционально NLP/ранжирование (Alem):

```dotenv
CONTRACTOR_AI_ENABLED=true
CONTRACTOR_AI_PROVIDER=openai-compatible
CONTRACTOR_AI_MODEL=qwen3-8
OPENAI_COMPATIBLE_URL=https://llm.alem.ai/v1
OPENAI_COMPATIBLE_API_KEY=ваш_ключ
CONTRACTOR_CACHE_STORE=file
```

После смены env: `php artisan config:clear`.

> Не используйте `composer run setup` для этого сценария: скрипт шаблона тянет миграции.

| --- | --- |
